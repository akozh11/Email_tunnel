# Email Tunnel

**Email Tunnel** — инструмент для организации сетевого туннелирования и передачи данных через протоколы электронной почты (SMTP / IMAP). Проект позволяет передавать трафик или выполнять удаленное управление в условиях строго ограниченных сетей, где разрешен только почтовый трафик.

---

## 🚀 Возможности

* **Туннелирование через Email:** Использование SMTP для отправки данных и IMAP для их получения.
* **Обход сетевых ограничений:** Работа в изолированных сегментах сети с доступом только к почтовым серверам.
* **Шифрование данных:** Защита передаваемой полезной нагрузки (AES / RSA).
* **Гибкая настройка:** Конфигурация через файлы параметров или переменные окружения (`.env`).
* **Асинхронная обработка:** Минимальные задержки при отправке и периодическом опросе ящика.

---

# 📐 Принцип работы

    Клиент упаковывает передаваемые данные или команды, при необходимости шифрует их и отправляет в виде почтового сообщения через SMTP.

    Сервер периодически проверяет почтовый ящик по протоколу IMAP, находит входящие сообщения туннеля, извлекает и расшифровывает полезную нагрузку.

    Ответ обрабатывается аналогичным образом в обратном направлении.

---

## 📋 Требования

* Python 3.8 или выше
* Учетная запись электронной почты с поддержкой SMTP и IMAP (Gmail, Yandex, Mail.ru и др.)
* Включенный «Пароль приложения» (App Password) в настройках безопасности почтового провайдера

## 🛠 Установка

1. **Клонируйте репозиторий:**
   ```bash

2. создайте в дерриктории проекта файл с указанным ниже текстом и заполните его личными данными
