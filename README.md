# Email Tunnel 4.0

Инструмент, который принимает запросы по электронной почте (IMAP), обрабатывает текст и изображения через Google Gemini и отправляет ответ обратно письмом (SMTP).

Управление белым списком, статистикой и безопасностью — через Telegram-бота.

Подходит, когда удобнее (или единственно возможно) общаться с ИИ через почту: ограниченная сеть, нет браузера, запросы от нескольких людей на один ящик.

> Объединение лучших частей веток `Email_tunnel_3.0` и `pre_release 4.0` + дополнительные улучшения.

---

## Что добавлено в этой версии

- **Конвертер LaTeX → обычный текст** (из версии 3.0).  
  Формулы в ответах Gemini автоматически превращаются в читаемый Unicode-текст  
  (`$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$` → `x = (-b ± √(b² - 4ac))/2a`).  
  Код в блоках ``` не трогается. Есть подсказка модели писать без LaTeX.

- **Предложение добавить нового отправителя**.  
  Если письмо пришло с адреса, которого нет в белом списке, владельцу в Telegram приходит сообщение с кнопками **✅ Добавить** / **🚫 Игнорировать**.  
  Повторно по тому же адресу не спамит (запоминает на 30 дней).

- **Кнопка «Очистить инциденты»**.  
  В разделе «Безопасность» и внутри журнала инцидентов можно полностью очистить журнал.

- **ИИ-классификатор безопасности** (из pre 4.0):  
  автобан / предупреждения / страйки, уведомления владельцу, обработка чувствительных запросов (кризис) без бана.

- **Двухфазная обработка почты**: письмо удаляется из ящика только после успешной отправки ответа.

- **Общий слой данных с файловым замком** (`storage.py`) — безопасно работает из двух процессов (`main.py` + `bot.py`).

- Исправлен `Requirements`: используется `pyTelegramBotAPI` (код на `telebot`).

---

## Возможности

- Приём писем только с доверенных адресов (белый список) + владелец.
- Обработка текста и вложений-изображений через Gemini.
- Ответ отправителю обычным письмом (`X-Email-Tunnel-Type: reply`).
- Telegram-бот: статистика, карточки адресов, история, безопасность, быстрое добавление.
- Повторные попытки при временной недоступности Gemini.
- Защита от почтовых петель (автоответы, bounce, свои ответы).

## Как это работает

```
Новый / доверенный отправитель
        │  письмо (текст и/или фото)
        ▼
   IMAP (опрос ящика)
        │
        ▼
   main.py
        ├── неизвестный адрес → Telegram: «Добавить?»
        ├── проверка security (ИИ-классификатор)
        ├── Gemini (+ LaTeX-конвертер)
        └── SMTP-ответ отправителю / в INBOX владельцу
                │
                └── storage.py ← bot.py (панель владельца)
```

## Установка

```bash
git clone https://github.com/akozh11/Email_tunnel.git
cd Email_tunnel

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r Requirements
```

Скопируйте настройки:

```bash
cp settings.example.py settings.py
```

Заполните `settings.py`:

- `TG_BOT_TOKEN` — токен от @BotFather
- `OWNER_ID` — ваш Telegram ID
- `MAIL_USER` / `MAIL_PASS` — почта и пароль приложения
- `IMAP_SERVER` / `SMTP_SERVER` и порты
- `GEMINI_API_KEY`

---

## Запуск

Запускаются **два процесса**:

```bash
# Почтовый цикл (опрос ящика и ответы)
python main.py

# Telegram-панель владельца (в другом терминале)
python bot.py
```

## Структура

| Файл            | Назначение                                      |
|-----------------|-------------------------------------------------|
| `main.py`       | Почтовый цикл, двухфазная обработка             |
| `mail.py`       | IMAP / SMTP, обнаружение неизвестных адресов    |
| `gemini.py`     | Запросы к Gemini + конвертер LaTeX              |
| `security.py`   | ИИ-классификатор, баны, уведомления             |
| `storage.py`    | Данные (адреса, история, статистика, инциденты) |
| `bot.py`        | Telegram-панель владельца                       |
| `settings.py`   | Конфигурация (не в git)                         |

Данные хранятся в каталоге `data/`.
