# Email Tunnel 2.0

Инструмент, который принимает запросы по электронной почте (SMTP/IMAP), обрабатывает текст и изображения через Google Gemini и отправляет ответ обратно письмом. Список доверенных отправителей и история запросов управляются через Telegram-бота.

Подходит для сценариев, когда удобнее (или единственно доступно) общаться с ИИ через почту: ограниченная сеть, нет браузера, запросы от нескольких людей на один ящик.

> Ветка: [`Email_tunnel_2.0`](https://github.com/akozh11/Email_tunnel/tree/Email_tunnel_2.0)

---

## Возможности

- Приём писем только с доверенных адресов (белый список).
- Обработка текста и вложений-изображений (inline и attachment) через Gemini.
- Ответ отправителю обычным письмом с заголовком `X-Email-Tunnel-Type: reply` — собственные ответы не обрабатываются повторно.
- Telegram-бот для владельца: добавление/удаление адресов, карточки отправителей, история запросов и ответов.
- Синхронизация белого списка: `data/allowed_senders.json` ↔ `ALLOWED_SENDERS` в `settings.py`.
- Повторные попытки при временной недоступности Gemini (503 / UNAVAILABLE).
- Почтовый цикл работает и без бота: если `aiogram` не установлен, используется статический список из `settings.py`.

## Как это работает

```
Доверенный отправитель
        │  письмо (текст и/или фото)
        ▼
   IMAP (опрос ящика)
        │
        ▼
   main.py  ──►  Gemini  ──►  SMTP-ответ отправителю
        │
        └──►  bot.py: запись в карточку адреса
```

1. `main.py` с заданным интервалом забирает новые письма из INBOX.
2. Письма не из белого списка и письма-ответы туннеля пропускаются.
3. Текст и картинки уходят в Gemini (`gemini-3.5-flash-lite` по умолчанию).
4. Ответ отправляется на адрес исходного отправителя.
5. Обработанные входящие письма удаляются из ящика (`\Deleted` + `EXPUNGE`).
6. Параллельно `bot.py` позволяет владельцу вести белый список и смотреть историю.

## Состав проекта

| Файл | Назначение |
|---|---|
| `main.py` | Цикл опроса почты, вызов Gemini, отправка ответа |
| `mail.py` | IMAP/SMTP: чтение, фильтр отправителей, удаление, ответ |
| `gemini.py` | Клиент Google GenAI, ретраи при 503 |
| `bot.py` | Telegram-бот управления адресами и историей |
| `settings.example.py` | Шаблон конфигурации (скопировать в `settings.py`) |
| `Requirements` | Зависимости Python |
| `data/` | Создаётся автоматически: `allowed_senders.json`, `requests_history.json` |

`settings.py` и каталог `data/` в git не коммитятся (см. `.gitignore`).

## Требования

- Python 3.8+
- Почтовый ящик с IMAP и SMTP (Mail.ru, Yandex, Gmail и др.)
- Пароль приложения (App Password), не обычный пароль от аккаунта
- Ключ Gemini API: [Google AI Studio](https://aistudio.google.com/api-keys)
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather) и ваш числовой Telegram ID ([@userinfobot](https://t.me/userinfobot))

## Установка

```bash
git clone -b Email_tunnel_2.0 https://github.com/akozh11/Email_tunnel.git
cd Email_tunnel

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

pip install -r Requirements
```

Если файл называется именно `Requirements` (без расширения):

```bash

```

```bash
cp settings.example.py settings.py
```

## Настройка `settings.py`

```python
TG_BOT_TOKEN = "токен от @BotFather"
OWNER_ID = 123456789          # ваш Telegram ID

MAIL_USER = "tunnel@example.com"
MAIL_PASS = "app-password"    # пароль приложения, не основной

IMAP_SERVER = "imap.mail.ru"
IMAP_PORT = 993
SMTP_SERVER = "smtp.mail.ru"
SMTP_PORT = 465

GEMINI_API_KEY = ""           # https://aistudio.google.com/api-keys

# Запасной список, если бот ещё не запущен или data/ пуст
ALLOWED_SENDERS = [
    # "friend@example.com",
]

POLL_INTERVAL_SECONDS = 10
```

Примеры серверов:

| Провайдер | IMAP | SMTP |
|---|---|---|
| Mail.ru | `imap.mail.ru:993` | `smtp.mail.ru:465` |
| Yandex | `imap.yandex.ru:993` | `smtp.yandex.ru:465` |
| Gmail | `imap.gmail.com:993` | `smtp.gmail.com:465` |

Для Gmail и большинства крупных провайдеров нужен именно App Password и включённый IMAP.

## Запуск

Нужны **два процесса**: почтовый цикл и Telegram-бот.

```bash
# терминал 1 — опрос почты и ответы Gemini
python main.py

# терминал 2 — управление белым списком
python bot.py
```

Для постоянной работы удобны `tmux`, `screen`, systemd или supervisor.

Почтовый цикл можно запускать отдельно: без бота он возьмёт адреса из `ALLOWED_SENDERS` в `settings.py`.

## Telegram-бот

Доступ только у `OWNER_ID`. Остальные получат «Доступ ограничен».

| Команда / действие | Что делает |
|---|---|
| `/start` | Главное меню |
| `/list` | Список доверенных адресов |
| `/add` или `/add addr@mail.com` | Добавить адрес (потом можно указать подпись) |
| `/cancel` | Отменить текущий ввод |
| Карточка адреса | Число запросов и история «запрос → ответ» |
| Удаление | С подтверждением; адрес убирается из JSON и из `settings.py` |

Данные:

- `data/allowed_senders.json` — белый список (источник истины для бота)
- `data/requests_history.json` — история, не больше 300 записей на адрес

После добавления или удаления бот зеркалирует список в блок `ALLOWED_SENDERS` внутри `settings.py`. Пароли и ключи при этом не затрагиваются.

## Использование с почты

1. Добавьте адрес отправителя через бота (или в `ALLOWED_SENDERS`).
2. Человек пишет на `MAIL_USER` обычное письмо: вопрос текстом и/или фото.
3. Через `POLL_INTERVAL_SECONDS` секунд письмо обрабатывается.
4. На тот же адрес уходит ответ с темой «Ответ от нейросети».

Пустые письма без текста и картинок игнорируются.

## Безопасность

- Не коммитьте `settings.py`, `.env` и каталог `data/`.
- Используйте пароль приложения, а не основной пароль почты.
- Белый список обязателен: иначе обработаются только явно разрешённые адреса (при пустом списке входящие просто не берутся).
- Бот отвечает только владельцу с `OWNER_ID`.
- История в JSON хранит обрезки запроса/ответа (до 2000 символов) — не кладите туда секреты.

---

## Ограничения

- Это не полноценный TCP/VPN-туннель. Канал связи — обычная почта, полезный сценарий — запросы к ИИ.
- Входящие обработанные письма удаляются из ящика.
- Модель Gemini задана в коде (`gemini-3.5-flash-lite`); при смене модели правьте `gemini.py`.
- Опрос ящика синхронный, с паузой `POLL_INTERVAL_SECONDS`.
